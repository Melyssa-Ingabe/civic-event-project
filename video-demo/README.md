# Demo Video

**Watch the walkthrough:** https://youtu.be/_iqQphCHbL0

The video covers:
- Backend API and PostgreSQL setup, and how the frontend connects to the API
- Normal user features: sign up, log in, events (filter, register), feedback, captioned promos, service requests, role guard
- Admin features: dashboard, create an event with an image, attendees and ratings, audio announcement upload, publish/unpublish, user enable/disable, service request responses
- Role-based access guards in the code, and the responsive layout
