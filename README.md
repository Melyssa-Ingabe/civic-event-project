# CivicEvent+ Project

Frontend built with **HTML, Tailwind CSS and jQuery** for the provided CivicEvents+ backend API.

- **Frontend setup, API connection, features and role-based access:** see [`frontend/README.md`](frontend/README.md)
- **Backend & database setup:** see [`backend/README.md`](backend/README.md)
- **Demo video:** see [`video-demo/README.md`](video-demo/README.md)

**Quick start**
1. Start the backend: `cd backend && npm install && npm run dev` (runs on `http://localhost:4000`)
2. Open `frontend/index.html` with VS Code Live Server
3. The API base URL is set in `frontend/js/config.js`
